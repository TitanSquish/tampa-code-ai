## Directory Purposes

**Root (project root):**
- Purpose: All application source code lives at the root level — no `src/` subdirectory
- Contains: Flask app, search module, GIS module, ingest script, runtime data files
- Key files: `code_website.py` (primary), `search.py`, `tampa_gis.py`, `ingest.py`

**`data/`:**
- Purpose: Source PDF documents used for ingestion; also contains the legacy parser script
- Contains: Tampa municipal code PDFs, CSD checklist PDF, `parse_tampa_docs.py` (alternate chunker)
- Key files: `data/tampa-code-5-27.pdf` — this is the PDF served at the `/pdf` route and the primary source indexed by `ingest.py`
- Note: PDF files are not committed to git (`.gitignore` excludes `data/*.pdf`). Generated parse outputs (`parsed_chunks.json`, `parsed_chunks.jsonl`) are also excluded.

**`.planning/codebase/`:**
- Purpose: GSD codebase map documents consumed by planning and execution agents
- Generated: Yes (by `/gsd-map-codebase`)
- Committed: Yes

**`.agents/skills/` and `.claude/skills/`:**
- Purpose: Project agent skill definitions (SKILL.md indexes and rule files)
- Generated: No (project configuration)
- Committed: No (`.gitignore` excludes `.claude` and `.agents`)

## Naming Conventions

**Files:**
- Snake_case for all Python files: `code_website.py`, `tampa_gis.py`, `ingest.py`, `search.py`
- Descriptive names indicating domain: `tampa_gis.py` (GIS integration), `code_website.py` (web app for code search)
- No package `__init__.py` files — flat module layout, no Python packages

**Functions:**
- Snake_case: `build_prompt`, `expand_query`, `gis_cache_get`, `suggest_tampa_addresses`
- Private helpers prefixed with single underscore: `_db()`, `_init_db()`, `_format_context()`, `_compose_prompt()`, `_get()`, `_err()`, `_find_address_candidates()`
- Boolean-returning functions use descriptive names: `is_inside_tampa_city_limits()`

**Variables:**
- Snake_case throughout
- Constants in UPPER_SNAKE_CASE: `PDF_PATH`, `DB_PATH`, `SEARCH_K`, `GIS_CACHE_TTL_SEC`, `INDEX_PATH`, `CHUNKS_PATH`, `EMBED_MODEL`
- Environment variable names match constant names: `SEARCH_K` ← `os.getenv("SEARCH_K")`

**Routes:**
- Hyphen-separated URL paths: `/address-review`, `/api/address-suggest`, `/api/property-context`
- API routes prefixed with `/api/`: `/api/address-suggest`, `/api/property-context`, `/api/feedback`
- HTML page routes at root level: `/`, `/login`, `/logout`, `/pdf`, `/ask`

**Chunk IDs:**
- Format: `{source}-{section_id}-chunk-{idx}` (e.g., `tampa_code_5_27-5-101.3-chunk-0`)
- Source values: `tampa_code_5_27`, `csd_sufficiency_checklist`, `tampa_code_22_11_21_28_6_19_17`
