# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note:** Phase 1 delivers the design system foundation — initialized tooling, token definitions, and a minimal app shell with routing stubs. It does NOT implement any real UI flows (those are Phase 3). The contract here locks the design language that Phase 3 must express.

| Property | Value |


```bash
npx shadcn@latest add button input label tabs card badge
```
These are the minimum set Phase 3 will build upon immediately. No additional components beyond this list in Phase 1.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline tight spacing |
| sm | 8px | Compact element spacing, icon-to-label gap |
| md | 16px | Default input padding, card body padding |
| lg | 24px | Section padding, card outer padding |
| xl | 32px | Layout horizontal padding, content max-width inset |
| 2xl | 48px | Major section breaks, vertical rhythm between page sections |
| 3xl | 64px | Page-level top/bottom padding on auth pages |

Exceptions:
- Touch targets (buttons, tab triggers) minimum 44px height — WCAG 2.5.5 compliance
- Sidebar/nav items: 12px vertical padding (between sm and md) for compact density

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 15px | 400 (regular) | 1.5 | Answer text, form labels, paragraph content |
| Label | 13px | 500 (medium) | 1.4 | Form field labels, badge text, metadata, muted notes |
| Heading | 20px | 600 (semibold) | 1.25 | Page section headings, card titles, tab panel headings |
| Display | 28px | 600 (semibold) | 1.15 | Auth page title ("Tampa Code AI"), login page header only |

**Font stack:** `"Geist", ui-sans-serif, system-ui, sans-serif`

**Rationale:** Geist is designed for product UIs. It reads clean at 13–15px, avoids the Inter/DM Sans monoculture, and has a civic-professional quality that suits a permit assistant. Not in the reflex reject list.

**Weights in use:** Exactly 2 weights — regular (400) for body and label, semibold (600) for headings and display. Phase 3 must not introduce additional weights.

**Line length cap:** Body text areas must have `max-width: 72ch` to prevent fatigue on wide viewports.

## Color

### CSS Variable Definitions (globals.css override)

The following values override shadcn's default Zinc preset to match the established Tampa Code AI brand spectrum (slate/blue, derived from the existing `code_website.py` palette at lines 428, 455–456, 560, 568).

```css
:root {
  /* Backgrounds */
  --background:        oklch(0.975 0.005 240);   /* #f4f7fb equivalent — slate-tinted off-white */
  --foreground:        oklch(0.14  0.015 240);   /* #1f2937 equivalent — near-black slate */

  /* Cards and surfaces */
  --card:              oklch(1.0   0.000 0);     /* pure white card surface */
  --card-foreground:   oklch(0.14  0.015 240);

  /* Popover */
  --popover:           oklch(1.0   0.000 0);
  --popover-foreground: oklch(0.14 0.015 240);

  /* Primary (brand blue — buttons, active tabs, links) */
  --primary:           oklch(0.49  0.19  255);   /* #2563eb equivalent */
  --primary-foreground: oklch(1.0  0.000 0);

  /* Secondary (muted surface — secondary buttons, hover states) */
  --secondary:         oklch(0.94  0.008 240);   /* #f1f5f9 equivalent */
  --secondary-foreground: oklch(0.35 0.015 240); /* #475569 equivalent */

  /* Muted (helper text, placeholders, metadata) */
  --muted:             oklch(0.94  0.008 240);
  --muted-foreground:  oklch(0.53  0.012 240);   /* #64748b equivalent */

  /* Accent (reserved — see below) */
  --accent:            oklch(0.94  0.012 250);   /* blue-50 equivalent #eff6ff */
  --accent-foreground: oklch(0.30  0.13  255);   /* #1e40af equivalent */

  /* Destructive */
  --destructive:       oklch(0.50  0.19  25);    /* #b91c1c equivalent */
  --destructive-foreground: oklch(1.0  0.000 0);

  /* Border and input */
  --border:            oklch(0.87  0.010 240);   /* #cbd5e1 equivalent */
  --input:             oklch(0.87  0.010 240);
  --ring:              oklch(0.49  0.19  255);   /* matches primary */

  /* Radius */
  --radius: 0.5rem;
}
```

### 60/30/10 Color Contract

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--background` `oklch(0.975 0.005 240)` | Page background, main content area |
| Secondary (30%) | `--card` white + `--border` slate | Cards, tab panels, nav header, sidebar, input fields |
| Accent (10%) | `--primary` blue `oklch(0.49 0.19 255)` | Primary CTA buttons, active tab indicator, focus ring, hyperlinks |
| Destructive | `--destructive` red `oklch(0.50 0.19 25)` | Destructive actions only (logout confirm, delete) |

**Accent reserved for (explicit list):**
1. Primary action buttons (`<Button variant="default">`)
2. Active/selected tab indicator underline or background
3. Focus ring (`--ring`) on all interactive elements
4. Text links in answer/citation output
5. Keyboard focus indicator

Accent must NOT be applied to: decorative backgrounds, section dividers, non-interactive badges, header bars, card backgrounds, or any element not in the list above.

**Do not use:** Pure black (#000) or pure white (#fff). All values are OKLCH-tinted toward hue 240 (blue-slate).

**Do not use:** `border-left` or `border-right` greater than 1px as colored accent stripes on cards, alerts, or list items (impeccable absolute ban).

**Do not use:** Gradient text (`background-clip: text` with gradient — impeccable absolute ban).

**Do not use:** The header gradient from the existing Flask app (`linear-gradient(135deg, #0f172a, #1d4ed8)`) — gradients carry over the legacy aesthetic. Use a flat `--foreground` or `--primary` surface for the app header instead.

**Elements (placeholder):**

2. Tab strip (shadcn `<Tabs>`): Two tabs — "Code Search" and "Address Review". Tabs span full content width.
3. Code Search tab panel placeholder:
   - Heading: "Code Search" — Heading typography
   - Body: "Ask a question about Tampa building codes and permit requirements." — Body typography, muted
4. Address Review tab panel placeholder:
   - Heading: "Address Review" — Heading typography
